{%- comment -%} Contents panel: the UI Library left text menu (`ipLeftMenu`, guide §3.3 / §4.8). The tree comes from _data/nav.json (generated by tools/build-nav.js from the output of tools/convert-dokuwiki.js) and is rendered by the recursive nav-tree.html include; the branch containing the current page is rendered open and that page is marked selected. The burger is the menu's own toggle and the only icon allowed in the panel: it slides the panel shut until only the burger is left, and the content moves across to take the space. assets/js/wiki.js wires it and remembers the choice. The search box sits under the sticky header, inside the panel, so it slides away with it. The "On this page" sub-menu for the selected page is filled in by assets/js/wiki.js, because the headings only exist once the article is rendered. {%- endcomment -%}
