{%- comment -%} Sidebar search box. The index is a static file generated by tools/build-search-index.js and filtered in the browser by assets/js/search.js, because GitHub Pages (build_type: legacy) cannot run a search plugin. The clear button replaces the browser's native `type="search"` cross, which is drawn in a fixed mid-grey and is invisible on the dark themes. {%- endcomment -%}
