The Excel Query Add-In allows you to query your data sources directly from Excel. You can query data by using the "IP Data Query" tab or by writing data query formulas.

There are some instructional videos demonstrating how to use the Excel Add-In in [this playlist](https://www.youtube.com/playlist?list=PLsVwx5rtV9c0duV5jln2IX9BIMDCCEWrY).

You can download a spreadsheet containing examples of all the formulas [here](https://appstore.intelligentplant.com/nuget/downloads/IP%20Excel%20Addin%20example.xlsx).
