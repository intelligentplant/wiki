OpMode consists of 3 main components. Modules,modes and areas.

<strong>Module</strong>: A collection of modes.
<strong>Mode</strong>: Mode component can be defined by 1 or more areas.
<strong>Area</strong>: Process PVs bounded by a period of time which indicate a mode. For better and more precise results you might want to define multiple areas.
