This page describes the release notes for [Controller Consultant](https://appstore.intelligentplant.com/Home/AppProfile?appId=0d298598590348dea1bc84b36945a9dc).

### 2026-10

Release date: 2026-10-30 <br />
Version: (v4.3.45)

##### New Features

- Added operator to select what type of comparison will alarm (Higher than, Lower than)
- Update report page to show type of comparison on limits
- Rename KPI tags to include the group name so they won't overlap with controllers on other groups
- Added Time in Manual KPI

##### Miscellaneous Changes
- Updated react version

#### 2026-06 (v4.3.38)

Release date: 2026-06-26

- <code>[Enhancement]</code>: Extending the list of recognised controller tags.
- <em>Under the hood dependency updates.</em>

#### 2020-07-Hotfix1

This release contains the following changes:

- Added demo dashboard that is viewable by every user.
- Added modal that lets the user know when a required data source is not available or authorised.
- Added fixes to licensing page.
- Added alias field to asset.
- Minor UI and bug fixes.
