The File System Event Sink provides a means of writing received events to file. This is mainly used for testing and inspecting incoming events.

NB. The output is a json representation of the full data core event object.

### Key Settings

- <strong>Output Folder</strong> <br /> By default this is <br /> `%ProgramData%\Intelligent Plant\Data Core Application Host\Service\Applications\App Store Connect\App_Data\Events`
