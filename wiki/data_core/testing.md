Intelligent Plant build highly configurable tools that operate on a distributed architecture. This is especially true of <strong>App Store Connect</strong> - the software customers deploy to their network to configure data connectivity and near-data monitoring.

App Store Connect tasks such as data streaming, historization and script tag calculation all introduce server load. We recommend trialling new configuration on a non-production environment and using the advanced telemetry built into App Store Connect to assess potential performance or scale issues.
