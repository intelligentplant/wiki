App Store Connect allows you to connect your data to off-the-shelf apps available in the Industrial App Store right now!

Tools such as Gestalt Trend and PnID are ready to connect to live data for immediate interactive analysis.

With an App Store Connection apps connect directly to your data. No need for time-consuming uploads.

<em><strong>Download the [App Store Connect Quick Reference](http://appstore.intelligentplant.com/nuget/downloads/App%20Store%20Connect%20Quick%20Reference.pdf)</strong></em>

### More Info {: .title}

App Store Connect is built on Intelligent Plant's Data Core framework. For information on the Data Core, see

- [Advanced Data Core Configuration](/wiki/data_core/advanced_data_core_configuration.html)

App Store Connect data storage drivers (Alarm Analysis and Edge Historian) is built on Intelligent Plant's Big Data Service and Elasticsearch. For more information, see

- [Big Data Service Advanced Configuration](/wiki/big_data_service/big_data_service_advanced_configuration.html)

### Custom Data Connections {: .title}

If you want to connect to a data source that we don't have a driver for, you can write your own custom driver. See here for more details:
